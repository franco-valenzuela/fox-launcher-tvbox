# Files for the box

| File | What it is |
|---|---|
| [`boot-hook.sh`](boot-hook.sh) | The three blocks the prompt can add to the box's start-up script: compressed memory, the compiler fix, and the advertising block for old Android. A template: the assistant copies only the blocks you chose |
| [`rk3229-mxq/debloat.txt`](rk3229-mxq/debloat.txt) | The apps turned off on the test box, with the reason for each group |

Do not copy these to a box by hand without reading [`PROMPT.md`](../PROMPT.md). Each one applies only when a check shows that the box has that problem.

Have a different box? Lists for hundreds of Android TV models live in [cleanyourtv](https://github.com/Gathin23/cleanyourtv/tree/main/examples). If your box is not there either, share your list in [Discussions](https://github.com/franco-valenzuela/fox-launcher-tvbox/discussions) once you have lived with it for a few days.
